# 시험 범위

## 고정 실행

| 연산 | 시험 항목 | 실행 식별자 | 반복 횟수 |
|---|---|---|---:|
| ADD | D6_APE addition depth 6 | `PACKAGE22_add_100_20260825_134055_850` | 100 |
| MUL | D6_MPE multiplication depth 6 | `PACKAGE22_mul_100_20260825_142742_621` | 100 |

시험일은 2026-08-25이다. 이 저장소에는 위 두 실행에서 나온 파일과 수치만
사용한다. 이후 재실행 결과나 다른 실행의 수치를 섞지 않는다.

## 논리 입력

- `m1`: 32 active slots x 16bit = 512bit
- `m2`: 32 active slots x 16bit = 512bit
- 전체 논리 입력: 1024bit
- 입력 생성 규칙: seed 42 + iteration index
- 서로 다른 입력: 연산별 100/100

입력은 시험을 위해 생성한 값이며 실제 물류 업무 데이터가 아니다.

## 암호 설정

시험 당일 터미널 로그에 기록된 설정은 다음과 같다.

- 구현: C++ / Microsoft SEAL BGV
- `poly_modulus_degree`: 16384
- `plain_modulus`: 65537
- 보안 설정: 128-bit, SEAL `tc128`
- batching: enabled

## 정합성 확인 항목

각 연산의 100회 실행에서 다음 내용을 기록했다.

- 입력 크기 1024bit 충족 여부
- c1·c2 암호문 저장과 재로딩
- 저장본과 재로딩본의 바이트 수·SHA-256 일치 여부
- 재로딩한 입력의 암·복호화 일치 여부
- 평문 기준값과 최종 복호화 결과의 일치 여부
- step1~step6 단계별 시간과 최종 통계

공개 저장소에는 `.seal` 암호문 파일 자체를 포함하지 않는다.
`raw_iterations.csv`에서 파일명·크기·SHA-256과 기록된 검증 결과는 확인할 수
있지만, 공개 파일만으로 암호문 재로딩을 다시 실행할 수는 없다.

## 시험 환경 정보

시험 장비의 상세 CPU·RAM·OS 정보는 시험절차서와 시험결과서의 확인 대상이다.
이 저장소의 동결 파일 6개에는 전체 장비 정보가 들어 있지 않으므로, 이
저장소만으로 시험 장비 사양을 입증하지 않는다.
