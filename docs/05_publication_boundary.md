# 공개 범위

## 이 저장소에서 확인할 수 있는 내용

- ADD·MUL 고정 실행이 각각 100회 기록을 포함하는지
- 기록된 1024bit 입력 조건과 암·복호화·최종 결과 확인 상태
- step1~step6의 원시 시간과 재계산 통계
- 각 단계의 100회 평균이 지정 기준 이내인지
- 동결 파일 6개의 크기와 SHA-256이 기준값과 일치하는지
- 회차별 TXT가 전체 터미널 로그의 해당 바이트 구간과 일치하는지

## 이 저장소만으로 확인할 수 없는 내용

- ETRI가 발급한 공인시험 성적서·인증서의 효력
- ETRI의 저장소 전체 승인·보증·추천
- 인제대학교 또는 ETRI 공식 GitHub 계정 여부
- 시험 실행과 암호문 재로딩의 독립 재현
- 실제 항만·물류 협력기관 데이터의 처리 결과
- SOCFAI 운영 시스템 전체의 현재 실행 상태
- 최댓값·P95·전체 체인 시간을 평균 판정 기준으로 사용하는 해석

회차별 TXT는 별도의 실행이나 추가 측정 결과가 아니다.

## 공개하지 않은 파일

- `.seal` 암호문 파일
- 시험 구현 실행파일·소스코드, 빌드 결과물과 실행 스크립트
- 인증정보, 인증서, 키, 지갑과 토큰
- 비공개 접속 주소와 배포 설정
- HWP/HWPX/PDF/PPTX 시험 문서와 행정 자료
- 실제 협력기관 데이터와 기관별 매핑 규칙
- 내부 인계 프롬프트와 비공개 파일 경로 기록

`tools/`에는 공개 자료의 검증과 회차별 열람본 생성에 필요한 도구만 포함한다.

## 공식 문서와의 관계

시험절차서·시험결과서·시험성적서는 별도의 작성·검토·승인 절차를 따른다.
공식 문서에 이 저장소를 연결할 때에는 검증된 커밋 전체 SHA와 태그를 함께
기록하고, 문서의 판정 기준과 이 저장소의 설명이 일치하는지 확인한다.
